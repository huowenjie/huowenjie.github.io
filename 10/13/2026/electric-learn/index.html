電路分析基礎學習知識彙總

此爲研習電路相關知識之雜記，隨性而爲，不間斷更新。

正弦量與相量

正弦信號

正弦信號乃指具有正弦或者餘弦函數形式的信號。

正弦電壓

正弦電壓可以表示爲：

  • $v(t) = V_m \sin(\omega t)$

其中：

  • $V_m$ 爲正弦電壓的幅度或者振幅（amplitude）
  • $\omega$ 爲角頻率，單位爲 rad/s（angular frequency）
  • $\omega t$ 爲正弦電壓的幅角（argument）

正弦電壓每隔 $T$ 秒就會重複一遍，所以稱 $T$ 爲正弦電壓的週期（period），且 $\omega T = 2\pi$，即 $T = \frac{2\pi}{\omega}$。
由於 T 爲週期，則又有 $v(t + nT) = v(t)$。
週期的倒數即爲頻率，故有$f = \frac{1}{T}$，所以 $\omega = 2\pi f$。頻率的單位爲赫茲（Hz）,表示每秒循環個數。

正弦電壓的一般表達式

正弦電壓的一般表達式：

  • $v(t) = V_m \sin(\omega t + \phi)$

相量

相量是一個表示正弦信號的幅度和相位的複數。相量提供了一種分析正弦電源激勵的線性電路的簡單辦法，否則這類電路的求解會很困難。

歐拉恆等式

  • $e^{\pm j\phi} = \cos\phi \pm j\sin\phi$

由上可知，$\cos\phi$ 和 $\sin\phi$ 可分別看作 $e^{j\phi}$ 的實部和虛部，即：

  • $\cos\phi = Re(e^{j\phi})$
  • $\sin\phi = Im(e^{j\phi})$

所以，已知正弦信號 $v(t) = V_m \cos(\omega t + \phi)$，由上式可得

  • $v(t) = Re(V_m e^{j(\omega t + \phi)})$
  • $v(t) = Re(V_m e^{j\phi} e^{j\omega t})$
  • $v(t) = Re(V e^{j\omega t})$，其中 $V = V_m e^{j\phi} = V_m \angle \phi$

電路元件的相量關係

電阻

電阻在相量域中的電壓電流關係服從歐姆定律。假設流過電阻R的電流爲 $i = I_m \cos(\omega t + \phi)$
由歐姆定律可知，其兩段的電壓爲 $v = iR = RI_m\cos(\omega t + \phi)$
在相量域中表示爲 $V = RI_m \angle \phi$

電感

對於電感而言，假設流過電感的電流爲 $i = I_m \cos(\omega t + \phi)$
則電感兩端的電壓爲 $v = L \frac{di}{dt} = -\omega L I_m \sin(\omega t + \phi) = \omega L I_m \cos(\omega t + \phi + \frac{\pi}{2})$
在相量域中表示則有 $V = \omega L I_m \angle \phi + \frac{\pi}{2}$

令 $I = I_m \angle \phi$ 且由歐拉恆等式得 $e^{j \frac{\pi}{2}} = j$
故有 $V = j \omega L I$

電容

對於電容 C 而言, 假設電容兩段的電壓爲 $v = V_m \cos(\omega t + \phi)$
則流過電容的電流爲 $i = C \frac{dv}{dt} = \omega C V_m \cos(\omega t + \phi + \frac{\pi}{2})$
在向量域中表示則有 $I = \omega C V_m \angle \phi + \frac{\pi}{2}$

令 $V = V_m \angle \phi$ 且由歐拉恆等式得 $e^{j \frac{\pi}{2}} = j$
固有 $I = j \omega C V$
則 $V = \frac{I}{j \omega C}$

無源元件的相量關係

電路元件 時域 相量域
電阻 $v = iR$ $V = IR$
電感 $v = L \frac{di}{dt}$ $V = j \omega L I$
電容 $i = C \frac{dv}{dt}$ $I = j \omega C V$

阻抗與導納

阻抗

電路的阻抗是指相量電壓 $V$ 和相量電流 $I$ 之比，單位歐姆($\Omega$)。

導納

導納爲阻抗的倒數，單位西門子($S$)。

無源元件的阻抗與導納

電路元件 阻抗 導納
電阻 $Z = R$ $Y = \frac{1}{R}$
電感 $Z = j \omega L$ $Y = \frac{1}{j \omega L}$
電容 $Z = \frac{1}{j \omega C}$ $Y = j \omega C$

阻抗和導納的直角座標形式表達

阻抗作爲一個複數，可以用直角座標形式表示爲： $Z = R + j X$
其中，R 爲電阻，X 爲電抗。

同理，導納也可以用直角座標形式表示： $Y = G + j B$
其中，G 爲電導，B 爲電納。

阻抗合併

N個串聯阻抗的等效阻抗，等於各個阻抗之和：$Z_{eq} = Z_1 + Z_2 + Z_3 + Z_4 + \cdots + Z_N$

N個並聯阻抗的等效阻抗，表示爲：$\frac{1}{Z_{eq}} = \frac{1}{Z_1} + \frac{1}{Z_2} + \frac{1}{Z_3} + \cdots + \frac{1}{Z_N}$
如果用導納來表示，則有 $Y_{eq} = Y_1 + Y_2 + Y_3 + Y_4 + \cdots + Y_N$

正弦穩態分析

分析方法

  1. 將電路轉換到相量域或頻域；
  2. 利用相應的電路分析方法（節點分析法、網孔分析法、疊加定理等）求解電路；
  3. 將所求得的相量轉換到時域；
  4. 由於 KCL 和 KVL 在交流電路中也是有效的，求解時可以靈活運用基爾霍夫電流和電壓定律。

交流功率分析

瞬時功率和平均功率

瞬時功率的概念

瞬時功率是指任一瞬間的功率，單位爲瓦特。瞬時功率是元件吸收能量的速率。
元件吸收的瞬時功率$p(t)$等於改元件兩端的瞬時電壓$v(t)$與流經該元件的瞬時電流i(t)的乘積。假設採用無源符號的國際慣例，則有：$p(t) = v(t)i(t)$

瞬時功率的一般情況

設電路的終端電壓和電流分別爲：
$v(t) = V_m \cos(\omega t + \theta_v)$
$i(t) = I_m \cos(\omega t + \theta_i)$

由 $p(t) = v(t)i(t)$ 和三角恆等式推得 $p(t) = \frac{1}{2} V_m I_m \cos(\theta_v - \theta_i) + \frac{1}{2} V_m I_m \cos(2 \omega t + \theta_v + \theta_i)$
上式表明，瞬時功率包含與時間無關的常量部分和與時間有關的正弦函數部分，正弦函數的角頻率爲$2\omega$。

瞬時功率隨時間變化，一般難以測量。

平均功率的概念

平均功率是指一個週期內瞬時功率的平均值，單位瓦特。平均功率可以表示爲 $P = \frac{1}{T} \int_{0}^{T} p(t) dt = \frac{1}{2} V_m I_m \cos(\theta_v - \theta_i)$
由上可知，平均功率與時間無關。

電阻性負載(R)在任何時刻均吸收功率，而電抗負載(L或C)吸收的平均功率爲零。

對於最大平均功率傳輸而言，負載阻抗 Z_L 必須等於戴維南阻抗 Z_{Th} 的共軛複數。當$R_L = R_{Th}且X_L = -X_{Th}$時，得到最大平均功率：$P_{max} = \frac{|V_{Th}| ^ 2}{8 R_{Th}}$
在負載爲純實數的情況下，令 $X_L = 0$，得到最大功率傳輸條件爲：$R_L = \sqrt{R_{Th}^2 + X_{Th} ^ 2} = |Z_{Th}|$，負載阻抗（電阻）等於戴維南阻抗的模。

有效值

週期性信號的有效值就是它的方均根值（rms）。 如下所示：

  • $I_{eff} = \sqrt{\frac{1}{T} \int_{0} ^ {T} i^2 dt}$   週期性電流的有效值
  • $V_{eff} = \sqrt{\frac{1}{T} \int_{0} ^ {T} v^2 dt}$   交流電壓的有效值
  • $X_{rms} = \sqrt{\frac{1}{T} \int_{0} ^ {T} x^2 dt}$   週期性信號的方均根

對於正弦信號 $i(t) = I_m \cos(\omega t)$ 和 $v(t) = V_m \cos(\omega t)$，有：

  • $I_{rms} = \frac{I_m}{\sqrt{2}}$
  • $V_{rms} = \frac{V_m}{\sqrt{2}}$

視在功率

視在功率（單位爲$V \cdot A$）是指電壓與電流的有效值乘積。$S = V_{rms} I_{rms}$
平均功率與視在功率的比值又被稱爲功率因數，$pf = \frac{P}{S} = \cos(\theta_v - \theta_i)$
功率因數是電壓與電流的相位角之差的餘弦值，也是負載阻抗幅角的餘弦值。

復功率

復功率（單位爲$V \cdot A$）是電壓相量有效值和電流相量有效值的共軛複數的乘積，它的值是一個複數，實部爲有功功率P，虛部爲無功功率Q。即：

  • 復功率 $S = P + jQ = V_{rms} I_{rms} ^ {*} = |V_{rms}||I_{rms}|\angle(\theta_v - \theta_i)$
  • 視在功率 $S = |V_{rms}| |I_{rms}| = \sqrt{P^2 + Q^2}$ 亦爲復功率之模
  • 有功功率 $P = Re(S) = S \cos(\theta_v - \theta_i)$
  • 無功功率 $Q = Im(S) = S \sin(\theta_v - \theta_i)$
  • 功率因子 $\frac{P}{S} = \cos(\theta_v - \theta_i)$

功率守恆

電源的復功率、有功功率、無功功率分別等於各個負載上的復功率、有功功率、無功功率之和。

功率因數的校正

不改變原始負載的電壓或電流，提高功率因數的過程稱爲功率因數校正。

由於大多數負載都是感性的，所以給負載並聯一個電容即可改善或校正負載的功率因數。在不改變有功功率的情況下，如果將功率因數從 $\cos \theta_1$ 提高到 $\cos \theta_2$，那麼所需並聯的電容容值C由下式確定：

  • $C = \frac{Q_C}{\omega V_{rms} ^ {2}} = \frac{P(\tan \theta_1 - \tan \theta_2)}{\omega V_{rms} ^ {2}}$

若負載是容性的，則負載因串聯一個電感器以實現功率因數校正，所需的分流電感器的值$L$可由下式確定：

  • $L = \frac{V_{rms} ^ {2}}{\omega Q_L}$ 其中，$Q_L = Q_1 - Q_2$，表示新、舊無功功率之差

BJT 雙極性晶體管器件

BJT 介紹

BJT 即爲雙極性晶體管。器件分爲兩種，PNP 型和 NPN 型，故晶體管則由兩個 PN 結構成，即發射結 EBJ 和集電結 CBJ。根據這兩個結的偏置條件，可得 BJT 不同的工作模式。 如下所示：

模式 EBJ CBJ
截止 反偏 反偏
放大 正偏 反偏
反向放大 反偏 正偏
飽和 正偏 正偏

放大模式一般被稱爲正向放大模式，當晶體管用作放大器時應用此模式。
當晶體管用作開關時，使用截止模式或飽和模式。
